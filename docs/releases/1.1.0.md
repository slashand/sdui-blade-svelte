# 1.1.0 release record

Core and Svelte share stable version `1.1.0`. This is a minor release because Core adds a public browser-history coordinator and a `close` action to the SDUI contract. It is not a silent patch bump from the local `1.0.2` manifests.

Both package manifests use version `1.1.0`. Svelte's release guard requires tag `v1.1.0`, a matching package version, and an exact Core `1.1.0` dependency in the manifest and frozen lockfile. Publishing a GitHub Release triggers the provenance-enabled npm workflow; a tag alone does not.

Core `1.1.0` was published to npm before Svelte's dependency was pinned. The Svelte lockfile records the registry integrity for that exact Core archive. React and Angular releases are separate and are not part of this release.

The release sequence is Core first, then Svelte. Each GitHub `v1.1.0` release must identify its reviewed source commit, complete its package workflow, and be checked against the npm registry version, `latest` distribution tag, and archive integrity. Browser qualification remains an owner-run check because demo servers are not started by this release operator.

Local preparation evidence on November 20, 2026: Core 56/56 tests, clean build and package dry-run passed; its package contains current ESM output without stale `.cjs` files. Svelte completed a frozen install against published Core `1.1.0`, `pnpm check` with zero errors and warnings, `pnpm lint`, production build, `svelte-package`, and `publint`. No app server or browser suite was started during this preparation.
